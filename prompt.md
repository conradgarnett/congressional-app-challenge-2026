# Prompt for Claude Code (Opus 5.5)

Act as a Senior Software Architect. Your task is to design a project framework for a web application with the following specifications:

## Project Overview
- **Purpose**: An interactive map application tailored for small businesses.
- **Tech Stack**: React and Next.js.
- **Integration**: OpenStreetMap (OSM) APIs.
- **Goal**: Provide a scalable, professional structure for a map-centric business tool.

## Requirements
1. **Framework Only**: Provide only the basic project structure and file organization. 
2. **No Code**: Do NOT generate any implementation code, logic, or boilerplate content within the files.
3. **Best Practices**: Use human-centric industry best practices for Next.js (App Router), React, and folder organization (e.g., separation of concerns, modularity, scalable directory patterns).
4. **Token Efficiency**: Limit your output tokens as much as possible. Be concise and direct.

## Expected Output
A clear, hierarchical directory tree representing the proposed file structure, with brief labels if a directory's purpose is not immediately obvious.
